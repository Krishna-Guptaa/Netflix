# 🎬 Netflix TV Shows & Movies Data Analysis

An end-to-end Netflix TV Shows and Movies Data Analysis project using Excel, MySQL, and Python to clean, analyze, and visualize Netflix content data and extract meaningful insights.

# 📌 Project Overview

This project explores Netflix's content library and analyzes different aspects of Movies and TV Shows, including genres, ratings, countries, release years, content duration, and content distribution.

Multiple tools were used throughout the analysis to demonstrate a complete data-analysis workflow.

# 🛠️ Tools & Technologies
Microsoft Excel — Data cleaning, initial exploration, filtering, and basic analysis
MySQL — Data querying, aggregation, filtering, grouping, and extracting insights
Python — Data analysis and transformation
Pandas — Data cleaning and manipulation
Matplotlib — Data visualization
Seaborn — Statistical visualization
Jupyter Notebook — Analysis and documentation

# 🎯 Objective

The objective of this project is to apply practical Data Analyst skills to a real-world dataset, including:

Data Cleaning
Data Transformation
SQL Queries
Exploratory Data Analysis
Data Visualization
Insight Generation

# 💡 Skills Demonstrated

Excel | MySQL | SQL | Python | Pandas | Matplotlib | Seaborn | EDA | Data Cleaning | Data Visualization

# 🚀 Conclusion

This project demonstrates an end-to-end approach to analyzing Netflix content data by combining Excel, SQL, and Python to transform raw data into meaningful insights and visualizations.
